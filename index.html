ANTES DE EMPEZAR
Todo en su sitio.
¿Qué abre la versión web de Nova Star?
El micrófono y el catálogo para acompañar a la aplicación de PC o TV. La partida de karaoke no se ejecuta completa en esta web. Usa el teléfono en la misma Wi-Fi que la pantalla.
¿Qué descarga necesito para Windows?
El instalador EXE instala la aplicación. El ZIP portátil conserva la carpeta de archivos: descomprímela completa antes de abrir el ejecutable. No muevas solo el EXE fuera de esa carpeta.
¿Y para teléfono o televisión?
Elige el APK correspondiente a tu dispositivo. Android TV / Google TV utiliza una descarga distinta de la de teléfono. No se trata de una aplicación para los sistemas Tizen o webOS. Cuando haya varias arquitecturas, se muestran en «Otras variantes».
