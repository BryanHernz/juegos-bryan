01Windows: ¿instalador o ZIP?+

El instalador crea los accesos directos. La versión portátil es una carpeta: extrae el ZIP completo y conserva todos los archivos junto al ejecutable.

02¿Qué APK corresponde a mi equipo?+

Teléfono usa el APK ARM64; Android TV, la variante ARMv7 publicada para TV. Comprueba la arquitectura de tu equipo. Las otras variantes están en Otras descargas.

Los APK son para Android, no para iPhone, Tizen ni webOS.

03¿Qué puedo hacer desde la web?+

Nova Star ofrece micrófono y catálogo como complemento del PC o televisor. No es el karaoke completo en el navegador.

El acceso web de Cartón Lleno continúa pendiente de configuración.

04¿Dónde encuentro las nuevas versiones?+

Al abrir el portal se consulta la última publicación estable de cada juego. El botón de actualizar permite volver a consultar. Si GitHub no responde, se indica que los enlaces son información guardada.
