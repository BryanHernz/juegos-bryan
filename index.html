02 / TODO LISTO PARA EMPEZARAYUDA DE INSTALACIÓN

Menos vueltas.
Más juego.

Elige el archivo para tu dispositivo. Las descargas vienen de los repositorios de versiones de cada aplicación.

Cada aplicación conserva sus propias versiones. Un archivo ausente no se reemplaza por otro incompatible.
01 ¿Qué descargo para Windows? +

Elige Windows · Instalador para instalar la aplicación y crear sus accesos directos. Cierra la aplicación antes de actualizar.

La opción Windows portátil es un ZIP: extrae toda la carpeta y conserva los archivos junto al ejecutable. No basta con copiar solo el .exe.

02 ¿Teléfono o Android TV? +

El botón Teléfono apunta al APK ARM64; el de Android TV al APK ARMv7 publicado para TV. En Otros archivos y arquitecturas están las variantes disponibles. Comprueba la arquitectura que admite tu dispositivo.

En el dispositivo, abre el APK descargado y autoriza la instalación desde esa aplicación solo cuando lo solicite. El archivo APK es para Android; no se instala directamente en iPhone, Samsung Tizen ni LG webOS.

03 ¿Qué puedo hacer desde la web? +

La web actual de Nova Star es el complemento de micrófono y catálogo para el PC o televisor. No equivale al juego completo de escritorio.

El acceso de Cartón Lleno se habilitará en este portal cuando se configure su dirección. Un botón sin enlace aparece deshabilitado, nunca redirige a una página inventada.

04 ¿Cómo veo una nueva versión? +

El portal consulta la última publicación estable al abrirse. También puedes pulsar el botón de actualizar de cada juego.

Si GitHub no responde o limita las consultas, verás un aviso y los últimos enlaces guardados. El historial de versiones sigue disponible. No hace falta iniciar sesión en GitHub para descargar archivos públicos.

05 ¿No aparece el instalador que busco? +

Solo se habilitan archivos que figuran en la publicación mostrada. Generar un instalador en un PC no lo publica automáticamente: primero hay que subirlo al repositorio de versiones.

No desactives las protecciones del sistema para abrir una descarga. Verifica la procedencia y usa los archivos publicados por el proyecto.
